# Changelog

All notable project changes will be recorded here.

## 1.0.0 — Initial public template

- Initial release of the Excel Purchase Register vs GSTR-2B reconciliation template.
- Invoice-level matching based on GSTIN and invoice number.
- Dashboard with KPI summaries and charts.
- Invoice-wise, exception, missing-invoice, duplicate, vendor-wise, and tax-head-wise reports.
- Blank-template behaviour checked with empty input sheets.
- Formula-driven fields retained in columns J:L of the input sheets.
